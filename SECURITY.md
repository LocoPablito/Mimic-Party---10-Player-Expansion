# Security and support

The Expansion installs Harmony hooks and writes validated capacity changes inside the current game's memory through the Core. It does not permanently patch GameAssembly.dll on disk. There is no telemetry, updater or remote downloader in the Expansion. BepInEx may separately retrieve its reference libraries.

Public archives contain the pinned managed plugin and documentation, not private diagnostic files, installer scripts, game assemblies or nested archives. SHA-256 manifests identify bytes, not safety or antivirus approval. Request review of unexpected detections rather than disabling protection.

Use the official Nexus page or GitHub Releases. Support reports should contain versions and sanitized error excerpts, not account data or game binaries. Native hooks must be compatible with the exact installed game build; a successfully installed hook is not a guarantee of every gameplay scenario.
