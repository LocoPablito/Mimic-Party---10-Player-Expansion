[size=5][b]Mimic Party — 10 Player Expansion[/b][/size]
[b]Version 1.1.2 · by arribbaa[/b]

Bring a bigger group into Mimic Party: up to [b]10 total players in Classic and Versus[/b], with free RED/BLUE team selection. No forced 5v5 — the mod does not impose equal team sizes.

[size=4][b]Which file should I download?[/b][/size]
[b]Recommended: Complete — Core included.[/b] It contains Expansion 1.1.2, Modding Core 1.0.0 and Interop Bootstrap 1.0.0. You do not need a separate Core download.
[b]BepInEx is NOT included[/b] and must be installed from the official link below.
Expansion ONLY is for users who already have the official Core package and its bootstrap. Do not install duplicate copies of the same DLL.

[size=4][b]Features[/b][/size]
[list]
[*]Classic and Versus capacity set to 10 total; configurable from 6 to 10.
[*]Free RED/BLUE selection in Versus. 4/6 and other uneven splits are within the intended total; no automatic balancing is imposed.
[*]Runtime capacity patches with a live native-helper self-check; no permanent replacement of GameAssembly.dll.
[*]Playback live-voice suppression hooks and rematch keep-lobby hooks.
[*]Clear startup/hook logs and local compatibility handling for the recognized generated CoreModule issue.
[/list]
Workshop pack handling is not replaced. On the documented build both mode cards show Up to 10 players, and Classic shows 1/10 when alone.

[size=4][b]Installation[/b][/size]
1. Close Mimic Party. When upgrading from an old v1.0.x on-disk patch, restore original game files first using its uninstaller or Steam Verify integrity.
2. Extract the official BepInEx archive into the folder containing Mimic Party.exe.
3. Extract the Complete package into the same folder BEFORE launching. Preserve the BepInEx/plugins and BepInEx/patchers paths.
4. Start normally through Steam. Initial interop generation can take longer; do not interrupt it. Create a PRIVATE lobby.

Installed author components:
BepInEx/plugins/MimicPartyModdingCore.dll
BepInEx/plugins/MimicParty10PlayerExpansion.dll
BepInEx/patchers/MimicParty.InteropBootstrap.dll

No installer EXE, command file or hotkey is needed. Use matching game/mod versions across participants when testing multiplayer. Do not upload or copy another player's generated interop files.

[size=4][b]Configuration[/b][/size]
After the first successful launch, close the game and open:
BepInEx/config/com.arribbaa.mimicparty.10playerexpansion.cfg
Set MaxPlayers = 10 in [Multiplayer]. Supported range is 6–10. This is a TOTAL room limit, not a limit per team.

Versus still requires at least two players to start. The message Need at least 2 players is a minimum, not the room maximum.
If a BepInEx console appears, minimize it instead of closing it during play. To hide it on later launches, set Enabled = false under [Logging.Console] in BepInEx/config/BepInEx.cfg, then restart.

[size=4][b]Update / uninstall[/b][/size]
The public Expansion DLL is the same one used in the successful 1.1.2 runtime test. Existing users do not need to regenerate working interop files. Do not rerun the old private FIX installers.
To uninstall, close the game and remove MimicParty10PlayerExpansion.dll from BepInEx/plugins. Keep the Core/bootstrap if another mod needs them. Runtime game-memory patches disappear when the game exits.

[size=4][b]Testing and limitations[/b][/size]
The documented Windows game run passed all 13 loader/hook/capacity checks. The native helper returned 10 for the tested selectors; screenshots confirm Classic 1/10 and both mode cards at 10. An older release was also tested with seven people according to the author.
A complete ten-client match, every team split and audio/rematch behaviour across a full large-group session have not been independently established. Installed hooks alone are not end-to-end gameplay verification.
The Complete package's new automatic bootstrap has separate metadata/load and regression validation; the earlier game session used the already-repaired installation and does not certify a fresh-game launch of this new component.
