SHORT DESCRIPTION
Expands private Mimic Party lobbies from 5 to up to 10 players with runtime voice isolation and Rematch keep-lobby support. Requires Mimic Party Modding Core.

FILE DESCRIPTION
v1.1 migrates the 10 Player Expansion to a BepInEx runtime plugin. No permanent GameAssembly patching. Requires Mimic Party Modding Core v1.0.0 or newer. All players in 6-10 player lobbies should use the same v1.1/Core versions.

IMPORTANT MIGRATION FROM v1.0.x
Before installing v1.1, users of the old on-disk v1.0.x patch must restore the original game file with the old uninstaller and verify Mimic Party through Steam. Do not run v1.1 on top of a v1.0.x-patched GameAssembly.dll.

INSTALLATION
1. Install BepInEx 6 Unity IL2CPP x64 build #788.
2. Install Mimic Party Modding Core v1.0.0+.
3. Extract the v1.1 archive directly into the Mimic Party game folder.
4. Confirm BepInEx/plugins/MimicParty10PlayerExpansion.dll exists.
5. Launch the game and create a private lobby.

FEATURES
- Up to 10 players in private lobbies.
- Host capacity support for players 6-10.
- Room/listing capacity follows the configured 6-10 player count.
- Existing stock voice-closing rules are preserved.
- Additional live-voice isolation is active during the active playback/performance window.
- Live voice returns after the performance window.
- Connected players remain together when Rematch starts.
- Genuine disconnect handling remains stock.
- Workshop sound packs remain handled by the game normally.

UNINSTALL
Close Mimic Party and delete BepInEx/plugins/MimicParty10PlayerExpansion.dll. The optional config file can also be removed. No GameAssembly restore is required for v1.1.
