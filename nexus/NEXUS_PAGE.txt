[size=5][b]10 Player Expansion for Mimic Party[/b][/size]
[b]Runtime 1.1.2 · by arribbaa[/b]

Up to [b]10 total players[/b] in private Classic and Versus lobbies. Versus keeps the game's RED/BLUE team selection. The mod does not enforce a five-player quota per side or equal teams.

[size=4][b]Required downloads[/b][/size]
[url=https://www.nexusmods.com/mimicparty/mods/3]BepInEx Pack for Mimic Party 1.0.0[/url]
[url=https://www.nexusmods.com/mimicparty/mods/2]Mimic Party Modding Core 1.0.0[/url]
Mimic Party Windows x64 / Steam, documented v0.1.73 build, Unity 6000.4.2f1.

[b]The current R3 main ZIP contains the Expansion only.[/b] Install both requirements separately. It does not include BepInEx, Core or Interop Bootstrap. The older Complete download already includes Core/Bootstrap and needs the Pack, not another Core copy.

[size=4][b]Installation[/b][/size]
1. Close the game. When migrating from the old v1.0.x on-disk patch, restore original game files with its uninstaller or Steam Verify integrity first.
2. Extract the BepInEx Pack into the folder containing Mimic Party.exe.
3. Extract the Core runtime ZIP into that same folder.
4. Extract this Expansion ZIP there; it adds BepInEx/plugins/MimicParty10PlayerExpansion.dll.
5. Launch normally through Steam and create a private lobby. Allow initial interop generation to finish.

Use matching versions across your group. Do not run old private repair installers or install renamed duplicate DLLs. A working 1.1.2 installation does not need its interop cache regenerated for R3.

[size=4][b]Features and configuration[/b][/size]
Classic and Versus share a total capacity of 10 by default. After a successful launch, close the game and open:
BepInEx/config/com.arribbaa.mimicparty.10playerexpansion.cfg

[code][Multiplayer]
MaxPlayers = 10[/code]

Range: 6-10; out-of-range values are clamped. Restart after changes. No automatic team balancing is imposed. The documented build shows updated mode-card values and Classic 1/10 when alone. Versus still needs at least two players to start; that is a minimum, not its capacity.

The Expansion also installs hooks intended to suppress live voice during playback and retain the lobby during rematch. It does not replace Workshop sound packs. Full large-group audio/rematch behaviour is not confirmed by hook installation alone.

[size=4][b]Compatibility[/b][/size]
The released Expansion 1.1.2 and Core 1.0.0 loaded in the documented Windows game session. The shared capacity helper returned 10 for the checked selectors. A complete ten-client session and every team distribution are not confirmed. The earlier seven-person session reported by the author used a previous release.
A fresh Windows game launch through the automatic Pack bootstrap route remains separately unconfirmed. Future game updates are not automatically supported.

[size=4][b]Update, removal and support[/b][/size]
R3 changes packaging and documentation only; the Expansion runtime DLL is unchanged. Documentation now lives in MimicParty10PlayerExpansion/ to avoid overwriting other guides.
Close the game and remove only BepInEx/plugins/MimicParty10PlayerExpansion.dll to uninstall the feature. Keep Core/Pack if other mods use them. Capacity patches are in memory and disappear at process exit.

For errors, check BepInEx/LogOutput.log and include versions plus a sanitized excerpt. Never post game binaries or private diagnostic ZIPs. Do not disable security protection as an installation step.
